# JARVIS — персональная ИИ-система

Настольное приложение для Windows 10/11 (Electron + React + TypeScript). **Готовы этапы 1–10 и «эффект Джарвиса»** (реальной телефонной связи пока нет — см. «Звонки») (HUD с голографическим шаром, естественный голос, камера, автозапуск): ядро —
ИИ-чат, локальная история, память, настройки и безопасность; **голос** (команды, слово «Джарвис», озвучка);
**управление компьютером** (файлы, программы, браузер, снимок экрана — только с вашего разрешения);
**ИИ-программист** (проекты, правка кода, тесты, Git, субагенты); **CRM «Сайберлос» только для чтения**; **ИИ-наставник**; **задачи по расписанию**; **звонки** (каркас с согласиями и симулятором); **доступ с телефона**; модульные выключатели. Полный план — в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), модель безопасности — в [docs/SECURITY.md](docs/SECURITY.md).

> Проект лежит в отдельной папке `JARVIS/` и не затрагивает остальные файлы репозитория.

## Быстрый старт (Windows)

1. Установите [Node.js LTS](https://nodejs.org) (нужна версия **22.13 или новее**) и, при желании, Git.
2. Откройте папку `JARVIS` и дважды щёлкните **`start-jarvis.bat`** — он сам установит зависимости и запустит приложение.

То же самое вручную:

```powershell
cd JARVIS
npm install
npm run doctor     # проверка среды
npm start          # сборка и запуск
```

Без API-ключа приложение работает в **демо-режиме**. Чтобы подключить настоящий ИИ, откройте
«Настройки» и введите ключ Anthropic (или задайте переменную окружения `ANTHROPIC_API_KEY`).

### Положить на рабочий стол

Папка создана внутри репозитория. Чтобы работать с ней с рабочего стола, скопируйте `JARVIS` на
`Рабочий стол` (после `git pull`) — приложение не зависит от остального репозитория.

## Команды

| Команда | Что делает |
|---|---|
| `npm run doctor` | проверяет Node, npm, Git, SQLite, Electron |
| `npm start` | собирает и запускает приложение |
| `npm run dev` | режим разработки (горячая перезагрузка интерфейса) |
| `npm test` | модульные и интеграционные тесты (vitest) |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run check` | типы + тесты |
| `npm run smoke` | сквозные тесты: запускают настоящий Electron (чат, безопасность, голос с поддельным микрофоном, управление компьютером), делают скриншоты |
| `npm run dist` | установщик Windows (`release/`, electron-builder) |

Данные (БД, секреты) хранятся в `%APPDATA%\JARVIS`. Для другого каталога задайте `JARVIS_DATA_DIR`.

## Что реализовано на этапе 1

- **ИИ-чат** с потоковым выводом, историей диалогов (SQLite), автоназванием, удалением.
- **Провайдеры**: Anthropic Claude (Messages API) и **демо-режим** без ключа и сети; выбор «Авто/Claude/Демо».
  Интерфейс `ChatProvider` позволяет добавлять других провайдеров.
- **Долговременная память**: предпочтения, проекты, задачи, факты — через интерфейс и по просьбе («Запомни: …»).
- **Инструменты** (`ToolRegistry`) с уровнями риска: время, чтение/запись/удаление памяти.
  Основа для файлов, браузера, CRM и обучения в следующих этапах.
- **Безопасность** (подробно в SECURITY.md):
  политика по ролям и уровням риска · окно подтверждения опасных действий (по умолчанию «Отклонить») ·
  кнопка **«Стоп»** (в чате и в окне подтверждения) · журнал действий с цепочкой хешей и запретом правки ·
  секреты шифруются средствами ОС (DPAPI) и не попадают в интерфейс · защита от инъекций из внешних данных ·
  запрет изменения «производственных» данных CRM · изолированный рендерер (sandbox, CSP, узкий IPC).
- **Настройки**: провайдер, модель, ключ, тема, порог подтверждений, свои инструкции, память вкл/выкл.
- **Тесты**: 273 модульных/интеграционных (включая настоящий Chromium, npm, Git и фиктивный сервер CRM) + четырнадцать сквозных smoke-тестов реального Electron.

## Главный экран «Джарвис» (HUD)

Приложение открывается на экране с **голографическим 3D-шаром** (облако точек, меридианы, вращающиеся кольца, ядро): он дышит в покое,
пульсирует в такт вашему голосу, «думает» фиолетовым и пульсирует в такт речи Джарвиса. Вокруг — часы, индикаторы МИК/КАМ/ИИ, панель
«Активность» (что он сейчас делает: «Читаю файл», «Запускаю проверки», «Смотрю на вас»), подпись ответа под шаром и нижняя панель:
микрофон, поле ввода, камера. Вкладки слева: **Джарвис · Чат · Память · Журнал · Настройки**.

**Естественный голос.** Робот-голос — это «голоса Windows». В **Настройки → Голос** выберите «Облачный синтез речи» и голос `onyx`
(глубокий мужской): ответы озвучиваются **по предложениям по мере генерации** (без ожидания конца ответа), с настраиваемой «манерой речи»
(по умолчанию — спокойный, уверенный ИИ-дворецкий). Кнопка «▶ Проверить голос». Нужен тот же ключ OpenAI, что и для распознавания (≈1–2 цента за минуту речи).

**Скорость и живость речи.** Настройки → Голос: «Скорость речи» (по умолчанию ×1.15, высота голоса сохраняется) и «Манера речи» (по умолчанию — живой темп без
растягивания). Озвучка стартует по запятой первой фразы, не дожидаясь точки, и следующие предложения запрашиваются заранее.

**Если Джарвис «слышит, но молчит».** На главном экране над нижней панелью теперь всегда видно, что он сделал с вашей фразой:
«Понял: …», «Услышал: … — но нет слова «Джарвис»», «…но я ещё говорю», «Слышу свою речь из колонок — пропускаю».
В режиме «Джарвис» каждая фраза должна начинаться со слова «Джарвис» (после его ответа 12 секунд можно продолжать без него); подсказка висит
на экране. Если озвучка зависает (бывает у голосов Windows), «сторож» через 20 секунд сам сбрасывает состояние. Колонки лучше заменить наушниками —
микрофон иначе слышит самого Джарвиса.

**Разговор без рук.** «Настройки → Голос → Режим микрофона → Джарвис», включите «Сразу слушать слово «Джарвис» при запуске» и «Запускать JARVIS вместе с Windows».
Скажите «Джарвис, который час?» — он ответит голосом; после ответа ещё 8 секунд можно продолжать без слова «Джарвис». Приветствие при запуске: «Добрый вечер, <имя>…».
«Стоп» — остановит речь и задачу. Эти режимы **выключены по умолчанию** и требуют вашего явного включения.

**Зрение (камера).** «Настройки → Камера → Разрешить» и кнопка «Камера» на главном экране (виден красный индикатор и превью).
Затем: «Джарвис, что я сейчас делаю?», «Джарвис, как я выгляжу?», «Покажи, что у меня в руке — что это?». Он делает **один кадр по запросу**
и описывает, что видит (Claude). Постоянного наблюдения нет. Кадры хранятся только до перезапуска приложения.

## Обновление по кнопке

**Настройки → Обновление JARVIS → «Проверить обновления» → «Обновить сейчас»** → «Перезапустить». Программа скачивает свежую версию с GitHub, заменяет свои файлы
(ваши ключи, историю и досье не трогает; защищены `node_modules`, `.env`, ваши данные; перед заменой старые файлы копируются в резервную папку), при необходимости
ставит новые компоненты и собирает приложение. Архивы вручную больше скачивать не нужно. При запуске JARVIS тихо проверяет обновления и показывает баннер.
Первое обновление «кнопкой» нужно поставить вручную (архив ветки), потому что кнопки в старых версиях ещё нет.

## ИИ-наставник (этап 6)

Вкладка **Наставник**: (1) **Обучение** — уроки по CRM с проверкой: объяснение с источником, тесты (неверный ответ — объяснение, верный — зачёт, считается доля «с первой попытки»),
практика в **тестовой** CRM (например, «создайте сделку «Тренировка <имя>», назначьте себя и поставьте задачу» — JARVIS проверяет по CRM и подсказывает, чего не хватает),
кнопка «Показать в CRM» подсвечивает нужную кнопку в браузере ассистента (вход в CRM выполняет сам сотрудник — пароли JARVIS не вводит);
(2) **Кабинет руководителя** — сотрудники (из команды CRM), назначенные курсы, прогресс и результаты, число замечаний в карточках CRM, **рекомендации по обучению** (ошибки → урок),
назначение курсов; (3) **База знаний** — документы (регламенты, скрипты продаж, руководства, частые вопросы), импорт из файла, **утверждение**: наставник использует только утверждённые документы,
любая правка возвращает документ в черновики. Ассистенту (в чате и голосом) доступны `kb_search` (ответ с источником `[«Название», ред. N]`; «в базе знаний этого нет» — без выдумывания правил),
`mentor_courses`, `mentor_progress`. Курсы: «Первые шаги в CRM», «Работа с заявками», «Производство и склад». Стартовая база и уроки составлены **по исходному коду вашей CRM**
(воронки, SLA, предоплата, роли) — правила вашей компании добавляйте и утверждайте сами. Учебные звонки — раздел «Звонки» (ниже).

## Задачи по расписанию (этап 8)

Вкладка **Задачи**: «каждое утро в 9:00 присылай сводку по CRM», «каждые 30 минут проверяй новые заявки», «вечерний итог дня» — шаблоны в один клик или своя задача
(по будням / каждый день / каждые N минут). Можно и голосом: «Джарвис, каждое утро в 9 присылай сводку по CRM» — он создаст задачу после вашего подтверждения.
Итог приходит уведомлением Windows и баннером; если ответ «OK» (ничего важного), уведомления нет. Работает, пока JARVIS запущен (включите автозапуск вместе с Windows).
**Безопасность фона:** без вас ассистент может только читать и анализировать — всё, что требует подтверждения (правка файлов, браузер, запуск программ, Git), в фоне **отклоняется**;
каждый запуск — не больше 6 шагов и 5 минут; «Стоп» прерывает; пропущенные дольше 12 часов запуски не выполняются «задним числом»; задачи не могут создавать другие задачи.
Нужен ключ Claude.

## Бесплатные модели и экономия

**Настройки → «Модели и экономия».** Включите одну или несколько моделей: **Ollama (Qwen на вашем компьютере, бесплатно)**, Google Gemini, Groq, OpenRouter (модели «:free»), Qwen (Alibaba) или свою.
Режим «Авто»: простые запросы (разговор, время, напоминания) отвечают бесплатные модели, сложные (код, анализ, много шагов, длинные запросы, слова «проанализируй/напиши код…») — Claude. Если бесплатная модель не отвечает или упёрлась в лимит — запрос уходит на следующую, а затем в Claude; если Claude недоступен — работают бесплатные. Режим «только бесплатные» никогда не тратит деньги на Claude.
**Приватность:** сторонним облачным моделям уходит только короткая системная подсказка **без** досье и памяти, и им не отправляются запросы, в которых участвуют CRM, файлы, экран, камера или досье — такие обрабатывает локальная модель (Ollama) или Claude. Ключи хранятся зашифрованными.
Для Ollama на 16 ГБ памяти подойдёт `qwen2.5:7b` (≈5 ГБ): установите Ollama с ollama.com и выполните `ollama pull qwen2.5:7b`. Честно: маленькие бесплатные модели слабее Claude, особенно в русском языке и в надёжном вызове инструментов — поэтому сложное остаётся за Claude. Бесплатные тарифы облаков меняются — названия моделей в настройках можно править.
**Картинки:** `image_generate` через OpenAI (тот же ключ, что для голоса; платно, каждый раз с подтверждением): «нарисуй логотип…». Генерация видео пока не подключена.

## Запуск программ голосом и браузер

**Программы.** В «Настройки → Доступ к компьютеру» включите «Разрешить все программы из меню Пуск» (одно подтверждение). После этого достаточно сказать или написать «открой Хром», «запусти Excel», «включи Телеграм» — запуск мгновенный, без обращения к модели и без окна подтверждения (всё записывается в журнал). Если подходит несколько программ («Яндекс»: Браузер или Музыка) или такой нет — решает модель и уточняет. Исключены командная строка, PowerShell, терминалы, редактор реестра, планировщик, службы, диспетчер задач, WSL и подобное; программы запускаются только без параметров.
**Браузер.** Отдельное окно со своим профилем: один раз войдите там в нужные сайты сами (пароли JARVIS не вводит) — вход сохраняется. Умеет: искать в интернете, открывать страницы, читать, прокручивать, возвращаться назад, нажимать, вводить текст, нажимать клавиши (Enter, Tab, стрелки…), делать снимок страницы. Поручения вроде «найди отель в Сочи на выходные до 6000 за ночь» — он ищет, сравнивает и показывает варианты; **оплату, бронирование и отправку форм делает только после вашего явного «да»**. Галочка «Не спрашивать подтверждение на обычные клики и ввод» ускоряет работу: всё равно спрашивает про открытие нового сайта, поиск, Enter, кнопки «оплатить/отправить/удалить/подтвердить/опубликовать», банки и платёжные сайты.
Честно: сложные сайты (капча, двухфакторный вход, сильно динамичные страницы) могут не поддаваться; «видит» он страницу как текст и список элементов (плюс снимок, если модель умеет смотреть картинки — бесплатные модели обычно не умеют).

## Telegram

Вкладка **Telegram**. Работает через **вашего собственного бота** (официальный Bot API): создайте бота у @BotFather (`/newbot`), вставьте токен — готово. Бот может писать только тем, кто сам ему написал; личный аккаунт Telegram не используется (против правил Telegram, рискует блокировкой аккаунта).
Что умеет: (1) **управление из Telegram** — привяжите свой аккаунт одноразовым кодом (`/start КОД`) и пишите боту поручения, как с телефона (те же ограничения: действия только с вашим разрешением и подтверждением на компьютере, опасные — никогда; `/stop` останавливает); (2) **ассистент читает и пишет**: «ответь Ивану в Telegram…» — отправка всегда с подтверждением, не больше 20 в час; (3) **автоответчик** (выключен по умолчанию): отвечает людям только текстом и только по вашим инструкциям (цены, график, FAQ) — о базе знаний, CRM и ваших данных он не знает, в первом ответе представляется ИИ, не больше 6 ответов в час на человека, «позовите человека» передаёт вопрос вам с уведомлением, ссылки в ответах вырезаются; в группах не отвечает.
Не сделано: рассылки по спискам (сознательно — спам), отправка файлов и картинок, ответы в группах, WhatsApp/Instagram/Max (нужны свои официальные доступы).

## Космический интерфейс (дизайн)

Фон — **Млечный Путь и Солнечная система издалека и сверху**: планеты движутся по орбитам (Сатурн с кольцами, Земля с Луной), пояс астероидов, Солнце с лучами, изредка пролетает комета; лёгкий параллакс от движения мыши. Ассистент — голографический шар из точек, парящий над системой.
Когда он говорит, шар **пульсирует и из роя точек проступает лицо** — без нарисованных линий: облик создают плотность и освещение точек (рельеф носа, глазниц, губ), глаза и рот — «созвездия» ярких точек, рот открывается от громкости голоса, по лицу скользит линия сканирования.
**Звуки:** клики, наведение, переключатели, переходы между разделами, «пробуждение» на имя, начало ответа, ошибки — синтезируются на лету (файлов нет), тихие; при включённом микрофоне ещё тише. Отключаются в Настройках, там же — тихий фон «гул космоса».



Окно открывается на весь экран (F11 — переключить; можно отключить в Настройках). Имя ассистента — «Системно» (меняется в Настройках; «Джарвис» тоже откликается). Когда ассистент говорит, шар превращается в голографическую голову с мимикой рта.
Голосом и текстом (без обращения к модели, мгновенно и бесплатно): «открой аналитику» — карточки со сводкой CRM; «покажи наш город» / «что у нас с бизнесом» — **город бизнеса** (районы — воронки, здания — стадии, высота — число сделок, красный — нарушены сроки); «вернись» — назад. Пока CRM не подключена, показываются помеченные «ПРИМЕР ДАННЫХ».

## Звонки наставника (этап 7, каркас)

Вкладка **Звонки**. Сделан **каркас и правила**, а не настоящая связь: звонки идут через **симулятор** — вы сами играете сотрудника в окне JARVIS, а Джарвис «звонит», представляется и проводит урок.
Чтобы звонить на настоящие номера, нужен оператор связи (SIP/облачная АТС) — это отдельная доработка: интерфейс `TelephonyProvider` для неё уже есть.
**Правила, которые уже работают и проверены тестами:** (1) звонок возможен только сотруднику, чьё **согласие внесено в реестр** (руководитель отмечает, что сотрудник согласился; согласие можно отозвать в один клик);
(2) только в разрешённое время (по умолчанию 09:00–20:00) и в пределах лимитов (10 в день, 2 на номер); (3) в начале разговора ИИ **представляется** («я программа, а не человек») и говорит, ведётся ли запись;
(4) **запись текста разговора — только при отдельном согласии** и удаляется кнопкой; без согласия сохраняется лишь итог (прошёл/отказался/не ответил, число верных ответов);
(5) «стоп» завершает звонок в любой момент, «больше не звоните» отзывает согласие; (6) в CRM звонки ничего не меняют; номера в журналах замаскированы; результаты тестов попадают в обучение сотрудника (по почте).
Сценарий звонка — жёсткий (не свободный разговор с моделью), поэтому представление и выход по «стоп» нельзя «заболтать».

## Доступ с телефона (этап 9)

**Настройки → «Доступ с телефона»** (по умолчанию выключено). Режим «по домашней сети Wi‑Fi» поднимает на этом компьютере маленький сервер: телефон открывает адрес вида `http://192.168.x.x:8787`,
вводит **6-значный код** (показывается только в окне JARVIS на компьютере, живёт 5 минут, одноразовый, после 5 неверных попыток сгорает) — и получает личный ключ. Дальше — тот же чат, можно диктовать голосом (если браузер телефона разрешает микрофон на `http`; иначе — текстом) и слушать ответы.
**Безопасность:** наружу (в интернет) ничего не открывается — сервер принимает только адреса домашней сети; ключи хранятся хешами; лимиты на попытки; отключить любой телефон можно в один клик (действует сразу).
**С телефона по умолчанию — только вопросы и анализ.** Действия, требующие подтверждения, с телефона запрещены, пока вы не включите галочку «Разрешить телефону просить действия» — и даже тогда подтверждение появляется **на компьютере** с пометкой «Запрос с телефона», а действия высокого риска (удаление, Git-отправка и т. п.) с телефона запрещены всегда.
Важно: через телефон можно задавать вопросы обо всём, что знает Джарвис (CRM, память, досье) — подключайте только свои устройства. Для доступа из другой сети нужен защищённый туннель (VPN) — это отдельная настройка, в программу сознательно не включена.

## Модули и масштабирование (этап 10)

**Настройки → «Модули»**: любой модуль (управление компьютером, ИИ-программист, CRM, наставник, расписание, телефония, доступ с телефона) можно полностью выключить — исчезают его инструменты и вкладки. Путь к нескольким компаниям/пользователям — в **[docs/SCALING.md](docs/SCALING.md)**.

## CRM «Сайберлос» (этап 5, только чтение)

Подключение к вашей CRM (Express + Prisma): воронки, заявки, задачи, команда, производство, склад. Вкладка **CRM** (плитки, менеджеры, замечания, кому нужно обучение)
и инструменты для ассистента: «Что нового в CRM?», «Какие заявки просрочены?», «Как работает Анна?», «Где узкие места?», «Что со складом?».
JARVIS умеет **только входить и читать** (список разрешённых путей зашит в программу, запись в CRM не реализована). Подробности, создание безопасной роли
«Джарвис (чтение)», тестовая среда и ПДн — в **[docs/CRM.md](docs/CRM.md)**. Настройки → «CRM «Сайберлос»».

## Досье: чтобы Джарвис знал вас

Вкладка **Досье** — семь разделов (обо мне, работа и бизнес, близкие и коллеги, цели, распорядок, как со мной общаться, чего не делать).
Три способа наполнить: писать вручную; **«Познакомиться с Джарвисом»** (он задаёт вопросы по одному, можно отвечать голосом, в конце показывает,
что собирается сохранить, — вы подтверждаете окном); **«Импорт из файла»** (txt/md/json: заметки, резюме, описание бизнеса, выгрузка памяти из ИИ-сервиса —
Джарвис выделит важное и предложит сохранить). Досье добавляется к каждому запросу к Claude (≈ до 6000 символов), поэтому он обращается к вам по имени,
помнит работу и близких, учитывает ваш стиль общения. Он знает о вас **только** это и «Память» и не выдумывает остальное. Выключатель — в Настройках.
**Пароли, ключи и номера карт программа в досье не принимает.** Досье лежит на компьютере без шифрования на уровне файла.

## Голос (этап 2)

Как включить: **Настройки → Голос** → ключ API распознавания речи (OpenAI-совместимый; по умолчанию
`https://api.openai.com/v1`, модель `gpt-4o-mini-transcribe`) → галочка «Разрешить использование микрофона» →
кнопка **«Микрофон»** в чате.

- **Режим «по кнопке»**: нажали, сказали фразу — она распознаётся, уходит в чат, микрофон выключается сам.
- **Режим «Джарвис»**: микрофон слушает постоянно; реагирует только на фразы, начинающиеся со слова «Джарвис»
  (также «жарвис», «jarvis»…). Остальное отбрасывается. Если сказать просто «Джарвис», он ответит «Слушаю» и ждёт команду 8 с.
- **«Стоп» / «остановись» / «Джарвис, отмена»** голосом прерывают задачу и озвучку.
- **Озвучка** ответов на голосовые команды: голоса Windows (бесплатно, без ключа) или облачный синтез речи.
- **Контроль микрофона**: главный выключатель в настройках (по умолчанию выключен, на уровне ОС-разрешений
  приложения — без него доступа к микрофону нет вообще); после запуска прослушивание всегда выключено;
  красный индикатор в боковой панели и на кнопке; кнопка «выкл.»; включение/выключение пишется в журнал.
- **Безопасность голоса**: голосовая команда проходит те же политики, что и текст; **подтвердить опасное действие
  голосом нельзя** — только кнопкой в окне. В журнал пишутся длительность и размер записи, но не текст разговоров.

Важно знать: звук (и в режиме «Джарвис» — каждая услышанная фраза) отправляется выбранному сервису
распознавания и тарифицируется им. Звуки без речи отсекаются локально по громкости.

## Управление компьютером (этап 3)

**Принцип: по умолчанию у ассистента нет доступа ни к чему.** Всё разрешается вами в
**Настройки → Доступ к компьютеру** через обычные окна Windows. Ассистент (ИИ) не может расширить свои права.

| Возможность | Как работает | Подтверждение |
|---|---|---|
| **Файлы** (`fs_*`) | Только внутри добавленных вами папок. Просмотр, поиск, чтение текстовых файлов (до 256 КБ) | чтение, просмотр — без; создание/перенос/открытие — **да**; перезапись и удаление (только в Корзину) — **да, «высокий риск»** |
| **Программы** (`app_*`) | Блокнот, Калькулятор, Paint + те, что вы добавили (.exe). Без аргументов и без командной строки | **да** |
| **Браузер** (`browser_*`) | Отдельное окно Edge/Chrome со своим профилем (не вашим). Читает текст страницы и пронумерованные элементы, нажимает, вводит текст | открытие, клик, ввод — **да**; чтение — без |
| **Снимок экрана** (`screen_capture`) | Основной монитор, уходит модели | **каждый раз**, «высокий риск», с миниатюрой в чате |

Что заблокировано всегда: корень диска, системные папки, вся папка пользователя, AppData, данные самого JARVIS;
файлы `.env`, `.ssh`, `*.pem`, `*.key`, `credentials*`; запуск `.exe/.bat/.ps1/.vbs/.lnk` через «открыть файл»;
сетевые пути `\\сервер\…`; `file://`, `localhost` и локальная сеть в браузере (пока вы сами не добавите адрес,
например тестовую CRM `localhost:5173`); ввод в поля паролей, карт и одноразовых кодов — их вводите только вы;
загрузки файлов из браузера; всплывающие окна.

Многошаговые задачи: ассистент может связать до 12 шагов подряд (например, найти файл → прочитать → создать отчёт);
каждое изменение всё равно ждёт вашего «Разрешить», а «Стоп» прерывает цепочку.

Для браузера нужен установленный **Microsoft Edge** (есть в Windows 10/11) или Google Chrome — скачивать ничего не нужно.

## ИИ-программист (этап 4)

Работает внутри ваших разрешённых папок (см. выше). Попросите, например: «Создай в папке Джарвис проект node-app calc, добавь функцию
сложения и тесты, проверь, что тесты проходят, и сделай коммит».

| Инструмент | Что делает | Подтверждение |
|---|---|---|
| `project_overview`, `code_search` | анализ проекта: стек, скрипты, структура, объём; поиск по коду | нет |
| `project_scaffold` | новый проект из шаблона: `node-app` (тесты на встроенном `node:test`), `static-site` | да |
| `code_edit` | точечная правка файла (фрагмент должен быть уникальным; окно показывает «было → стало») | да |
| `run_script` | `npm run test / build / lint / typecheck / check`; вывод и код выхода возвращаются ассистенту, он исправляет и повторяет | да; окно показывает **точную команду** скрипта; подозрительная команда (curl, powershell, rm -rf, git push…) → «высокий риск» с предупреждением |
| `npm_install` | установка зависимостей, по умолчанию `--ignore-scripts` | да, «высокий риск» |
| `git_status/diff/log` | чтение состояния | нет |
| `git_init`, `git_branch`, `git_commit` | репозиторий, ветка, коммит (откажет, если среди изменений секреты — `.env`, ключи) | да |
| `git_push` | отправка текущей ветки в origin, без force | да, «высокий риск» |
| `delegate_task` | поручает задачу **субагенту**: `developer` (пишет и чинит), `tester` (запускает проверки, пишет тесты, не правит код), `reviewer` (ревью, только чтение) | действия субагента подтверждаются так же; в окне пометка «агент: …» |

Как ассистент чинит ошибки: `run_script test` → читает вывод → `code_edit` → снова тесты, до 12 шагов подряд; «Стоп» прерывает цепочку и убивает запущенные процессы.
Субагенты (до 15 шагов каждый) получают только свои инструменты, не могут делегировать дальше и не имеют `git_push`.

Безопасность запуска кода: процессы запускаются **без командной оболочки**, без доступа к вашим ключам (окружение очищено от токенов и API-ключей),
с таймаутом 3 мин, лимитом вывода и убийством всего дерева процессов; Git запускается с отключёнными хуками и `fsmonitor` (вредоносный репозиторий
не выполнит код при `git status`); запись в `.git` и `node_modules` запрещена. **Но тесты и скрипты проекта — это код с вашими правами**: они могут
сделать всё, что можете вы. Поэтому каждое выполнение требует вашего «Разрешить», а окно показывает точную команду.

## Ограничения этой версии (честно)

- **Новый интерфейс, голос и камера проверены в Linux-контейнере** (настоящий Electron под Xvfb, поддельные микрофон и камера, поддельный
  сервер голоса). **Не проверено на Windows и вживую:** как звучит `onyx` по-русски и как Claude описывает ваши кадры; шрифт Bahnschrift
  (если его нет — подставится Segoe UI); автозапуск через реестр Windows; плавность шара на вашей видеокарте.
- Слово «Джарвис» определяется по тексту распознавания (облачный STT), поэтому реакция с задержкой 1–3 с, а в постоянном режиме каждая фраза тарифицируется.
- Шар — 3D на Canvas 2D (облако точек), не настоящая 3D-модель: он не «собирается» в объекты и не показывает документы/карты, как в фильмах.
- Камера: только по запросу и только описание кадра; не распознаёт людей, эмоции «по лицу» Claude описывает сдержанно (запрещено делать выводы о здоровье и личности).

- **Этапы 5–10 проверены только в Linux-контейнере** (Electron под Xvfb, фиктивный сервер CRM, симулятор звонков, телефон — это второй Chromium с мобильным экраном). Не проверено: работа с **настоящей** CRM (подключение, роль «Джарвис (чтение)»), реальные звонки (связи нет), открытие страницы шлюза с настоящего телефона (брандмауэр Windows может спросить разрешение при первом включении режима «по Wi‑Fi»; микрофон на телефоне часто требует `https`).
- Мобильный доступ только по домашней сети; нет шифрования канала (`http` внутри дома) и нет доступа «из любой точки» — для этого нужен VPN/туннель.
- Телефония — каркас: реальных звонков нет, распознавания речи по телефонной линии нет.
- **Этап 4:** основной сценарий (Node.js/npm + Git) проверен автотестами и в настоящем Electron под Linux. Не проверено: запуск npm и Git на Windows
  (поиск `npm-cli.js`, убийство дерева процессов через `taskkill`), реальная работа субагентов с моделью Claude (в тестах — заглушка модели,
  поэтому качество кода и умение самостоятельно чинить сложные ошибки не оценены), `git push` на настоящий сервер.
  Субагенты в демо-режиме (без ключа Claude) недоступны. Другие стеки (Python, .NET, Docker) пока без готовых инструментов запуска; код на них можно
  читать и править, но запускать нечем. Скрипты `start`/`dev` (долгоживущие серверы) запускать нельзя. Правка файлов только текстовая и целиком в памяти (до 1 МБ).
- **Этап 3 проверен в Linux-контейнере** (настоящий Electron под Xvfb, Chromium вместо Edge). **Не проверено на Windows:**
  Корзина (`shell.trashItem`), запуск программ, выбор папок в окне Windows, Edge, снимок экрана на вашем мониторе.
- **Нет «Windows UI Automation»** (управление чужими окнами: клики по кнопкам любой программы). Ассистент умеет только
  запускать программы и работать в своём браузере. Это запланировано отдельно: нужен вспомогательный процесс и аккуратная модель прав.
- Браузер читает страницу как текст и список элементов, **картинки страниц не анализирует** (для этого есть снимок экрана);
  сложные сайты (капча, canvas-приложения, Shadow DOM) могут не работать.
- Снимок экрана — только основной монитор, весь экран целиком (без выбора окна).
- Защита адресов браузера не рассчитана на DNS-подмену (когда публичное имя указывает на локальный адрес);
  и всё равно действует подтверждение каждого клика.
- **Голос проверен на поддельном микрофоне** (wav-файл) и поддельном сервере распознавания. С реальным
  микрофоном, реальным API и русскими голосами Windows не проверялось: качество распознавания слова «Джарвис»
  зависит от выбранной модели. Нет локального (офлайн) распознавания; слово-активатор определяется по тексту
  распознавания, а не отдельным детектором, поэтому режим «Джарвис» платный и с задержкой 1–3 с.
- Свой микрофон в Windows должен быть разрешён: Параметры → Конфиденциальность → Микрофон.
- История и память в БД лежат **без шифрования на уровне файла** (защита — права учётной записи Windows/BitLocker).
  Шифрование — только для секретов.
- Демо-режим понимает несколько фраз по шаблону — это не ИИ.
- Ответы выводятся простым текстом, без Markdown-разметки.
- Работа под **Windows** (сборка установщика, DPAPI) на этом этапе не проверялась: разработка и проверка
  велись в Linux-контейнере (Electron 45 под Xvfb). Установщик `npm run dist` не собирался.
- Проверка ключа и работы Claude «вживую» не выполнялась (ключа в среде разработки нет); адаптер покрыт
  тестами только в части преобразования сообщений и обработки ошибок.
- Claude Agent SDK пока не подключён: он понадобится на этапах 4 и 8 (мультиагентность), совместимость
  с упаковкой Electron нужно проверить перед использованием.

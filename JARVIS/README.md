# JARVIS — персональная ИИ-система

Настольное приложение для Windows 10/11 (Electron + React + TypeScript). **Этап 1 готов**: ядро —
ИИ-чат, локальная история, память, настройки и базовая безопасность. Полный план — в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), модель безопасности — в [docs/SECURITY.md](docs/SECURITY.md).

> Проект лежит в отдельной папке `JARVIS/` и не затрагивает остальные файлы репозитория.

## Быстрый старт (Windows)

1. Установите [Node.js LTS](https://nodejs.org) (нужна версия **22.13 или новее**) и, при желании, Git.
2. Откройте папку `JARVIS` и дважды щёлкните **`start-jarvis.bat`** — он сам установит зависимости и запустит приложение.

То же самое вручную:

```powershell
cd JARVIS
npm install
npm run doctor     # проверка среды
npm start          # сборка и запуск
```

Без API-ключа приложение работает в **демо-режиме**. Чтобы подключить настоящий ИИ, откройте
«Настройки» и введите ключ Anthropic (или задайте переменную окружения `ANTHROPIC_API_KEY`).

### Положить на рабочий стол

Папка создана внутри репозитория. Чтобы работать с ней с рабочего стола, скопируйте `JARVIS` на
`Рабочий стол` (после `git pull`) — приложение не зависит от остального репозитория.

## Команды

| Команда | Что делает |
|---|---|
| `npm run doctor` | проверяет Node, npm, Git, SQLite, Electron |
| `npm start` | собирает и запускает приложение |
| `npm run dev` | режим разработки (горячая перезагрузка интерфейса) |
| `npm test` | модульные и интеграционные тесты (vitest) |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run check` | типы + тесты |
| `npm run smoke` | сквозной тест: запускает настоящий Electron и проходит сценарии, делает скриншоты |
| `npm run dist` | установщик Windows (`release/`, electron-builder) |

Данные (БД, секреты) хранятся в `%APPDATA%\JARVIS`. Для другого каталога задайте `JARVIS_DATA_DIR`.

## Что реализовано на этапе 1

- **ИИ-чат** с потоковым выводом, историей диалогов (SQLite), автоназванием, удалением.
- **Провайдеры**: Anthropic Claude (Messages API) и **демо-режим** без ключа и сети; выбор «Авто/Claude/Демо».
  Интерфейс `ChatProvider` позволяет добавлять других провайдеров.
- **Долговременная память**: предпочтения, проекты, задачи, факты — через интерфейс и по просьбе («Запомни: …»).
- **Инструменты** (`ToolRegistry`) с уровнями риска: время, чтение/запись/удаление памяти.
  Основа для файлов, браузера, CRM и обучения в следующих этапах.
- **Безопасность** (подробно в SECURITY.md):
  политика по ролям и уровням риска · окно подтверждения опасных действий (по умолчанию «Отклонить») ·
  кнопка **«Стоп»** (в чате и в окне подтверждения) · журнал действий с цепочкой хешей и запретом правки ·
  секреты шифруются средствами ОС (DPAPI) и не попадают в интерфейс · защита от инъекций из внешних данных ·
  запрет изменения «производственных» данных CRM · изолированный рендерер (sandbox, CSP, узкий IPC).
- **Настройки**: провайдер, модель, ключ, тема, порог подтверждений, свои инструкции, память вкл/выкл.
- **Тесты**: 35 модульных/интеграционных + сквозной smoke-тест реального Electron.

## Ограничения этой версии (честно)

- Только текст: **голоса нет** (этап 2); кнопка микрофона отключена. Управление ПК, браузером, файлами,
  CRM, обучение и телефония — следующие этапы; ассистент сам сообщает, что они недоступны.
- История и память в БД лежат **без шифрования на уровне файла** (защита — права учётной записи Windows/BitLocker).
  Шифрование — только для секретов.
- Демо-режим понимает несколько фраз по шаблону — это не ИИ.
- Ответы выводятся простым текстом, без Markdown-разметки.
- Работа под **Windows** (сборка установщика, DPAPI) на этом этапе не проверялась: разработка и проверка
  велись в Linux-контейнере (Electron 45 под Xvfb). Установщик `npm run dist` не собирался.
- Проверка ключа и работы Claude «вживую» не выполнялась (ключа в среде разработки нет); адаптер покрыт
  тестами только в части преобразования сообщений и обработки ошибок.
- Claude Agent SDK пока не подключён: он понадобится на этапах 4 и 8 (мультиагентность), совместимость
  с упаковкой Electron нужно проверить перед использованием.

## Совместимость (проверено при разработке)

Node.js 22.23 (локально) · Electron 45.4.1 (внутри Node 24.22, `node:sqlite` доступен) · React 19.3 ·
Vite 8.3 · Vitest 5.1 · TypeScript 7.0 · `@anthropic-ai/sdk` 1.12. SQLite — встроенный `node:sqlite`
(помечен в Node как experimental, API может измениться), поэтому нет нативной компиляции под Windows.
